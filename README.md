# Astro Raiders

**Astro Raiders** is a 2D pixel‑art space shooter built with Unity.  
The player controls a ship and must shoot waves of enemy ships while avoiding attacks.

This project is mainly created as a **learning project** to practice game development with Unity.

## Engine
Unity **6000.3.14f1 LTS**

## Gameplay
- Control a spaceship
- Shoot projectiles
- Fight waves of enemy ships
- Arcade‑style 2D gameplay
